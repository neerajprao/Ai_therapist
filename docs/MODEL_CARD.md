# Model card: SoulSync speech emotion classifier (v2)

Generated by `python -m eval.make_docs` from `eval/results/`. Numbers are not typed by hand.

## Summary

A `facebook/wav2vec2-base` encoder fine-tuned to classify a 3-second speech clip as **happy, sad, angry, neutral or anxious**. Used in SoulSync to give the language model a hint about the speaker's tone. It is a demo component, not a clinical or diagnostic tool.

| | |
|---|---|
| Architecture | Wav2Vec2ForSequenceClassification, CNN feature encoder frozen, 90,369,413 trainable parameters |
| Input | 16 kHz mono, 3 s, zero-mean unit-variance per clip, zero-padded. Longer audio: 3 s windows with 50% overlap, probabilities averaged |
| Output | 5-way softmax |
| Formats | PyTorch (378.3 MB), ONNX FP32 (378.5 MB), ONNX INT8 (122.1 MB) |

## Data

Four acted, English-language corpora via the Kaggle collection `uldisvalainis/audio-emotions`: RAVDESS (2076 files, 24 speakers), CREMA-D (7442 files, 91 speakers), TESS (2800 files, 2 speakers), SAVEE (480 files, 4 speakers). Details and problems found in the packaging: [DATASET.md](DATASET.md).

- "Fearful" is used as "anxious". "Disgusted" and "surprised" are dropped ({'disgusted': 1923, 'surprised': 652}).
- RAVDESS song clips are excluded.
- Labels are read from filenames. The folder labels are wrong for 405 SAVEE clips.

### How much to trust these numbers

- The confidence intervals resample clips. They do not cover seed-to-seed variation (one training run) or the fact that there are only 14 test speakers.
- Validation macro-F1 was 81.8% and test macro-F1 is 71.1%. The gap shows how much results move between two sets of 14 speakers.
- Trained without TESS and tested on TESS (an unseen corpus, 2 unseen speakers): 60.6% accuracy, 53.4% macro-F1 on 2000 clips.

### Baseline

The v1 notebook's recipe (RAVDESS only, split by file, `wav2vec2-base-960h`) was reproduced because the original weights were unavailable. It scores 61.9% on its own file-level validation split and 32.4% accuracy (28.8% macro-F1) on this test set. The original notebook reported 82.9% on its leaky validation split, so the reproduction is weaker than the original model was and the "before" figure is likely pessimistic.

### Emotion2Vec and the ensemble

v1 discarded every Emotion2Vec score through a label mismatch. With the mapping fixed, on the same test set: Emotion2Vec alone 89.3% accuracy; ensemble at Wav2Vec2 weight 0.4 89.5%. The weight was chosen on validation (macro-F1 gain +9.2 points, 95% CI +6.9 to +11.7).

**Read this number with care.** Emotion2Vec is a public model fine-tuned on EmoBox, a collection of academic emotion corpora. If that includes RAVDESS, CREMA-D or SAVEE, it has heard our test speakers, and its score here is not a speaker-independent result. Nearly all of the ensemble's accuracy comes from Emotion2Vec; the fine-tuned Wav2Vec2 adds little on top of it.

## Limitations

- **Acted speech.** Actors reading fixed sentences exaggerate emotion. Performance on spontaneous speech is unmeasured and expected to be lower.
- **English only.** Mostly North American and British speakers.
- **Five coarse classes.** "Anxious" is a relabelled "fearful". Real anxiety rarely sounds like acted fear.
- **Short clips.** Trained on 3-second windows of single sentences.
- **Not a clinical tool.** It must not be used to assess mental state, risk or diagnosis. In SoulSync it only adjusts the tone of a reply, and the UI says the estimate is often wrong.
- **One seed, one run.**
