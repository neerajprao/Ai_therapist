**SoulSync: voice-first AI companion with emotion recognition and long-term memory** (Python, PyTorch, FastAPI)

- Fine-tuned Wav2Vec2 for 5-class speech emotion recognition on 7,635 clips from 4 corpora, reaching 71.1% macro-F1 on 14 held-out speakers after replacing a leaky file-level split with a speaker-independent one and correcting 405 mislabelled clips found in the source dataset.

- Built per-user RAG memory with ChromaDB and MiniLM embeddings (semantic search with a tuned cosine-distance threshold), scoring Hit@3 of 81% and 0% false recall on a held-out synthetic test set with 0 cross-user leaks.

  - Proof: `eval/results/latency_local.json`, `tests/`, `.github/workflows/tests.yml`

## Notes before you use these

- The 71.1% figure is on **acted** speech. If asked, say so; it is the honest speaker-independent number and it is the one to quote.
- Do not quote the ensemble figure (89.5%) as your model's accuracy. Most of it comes from the pretrained Emotion2Vec model, whose training data probably overlaps the test corpora.
- Do not claim an improvement "from 83%". The 83% was a leaky validation score. The reproduced v1 recipe scores 32.4% on the new test set, but that reproduction is weaker than your original model, so avoid a before/after claim altogether.
- "Docker" and "Groq" are not in the bullets. The Dockerfile and the Groq backends are written and covered by tests with fakes, but the image has not been built and the Groq path has not been run against the live API. Add them after a real run.
- The CI workflow exists but has never run, because nothing has been pushed yet. Check that it passes on GitHub before relying on that claim.
- The memory test set has 21 held-out follow-ups and 8 unrelated questions, written by you. Call it a synthetic test set if asked.
